# UNITE workspace instructions

This workspace contains multiple independent UNITE Git repositories.

Before working on a task, read `unite-meta/AGENTS.md` relative to this workspace
root. The shared checkout may alternatively be named `.github`. Read its project
overview, repository map, and relevant topic documents as directed by its README.
Resolve shared documentation links relative to that shared checkout.

Before editing a component, read its own `AGENTS.md`, README, and any more
specific instructions applicable to the files being changed. Component guidance
supplements the shared rules. Inspect Git status in each affected repository;
run Git and build commands in the intended repository rather than assuming the
whole workspace is one Git project.

If the shared checkout is unavailable, use the instructions at
[dkfz-unite/.github](https://github.com/dkfz-unite/.github/blob/main/AGENTS.md).
If those are also unavailable, report the missing context and proceed only with
what accessible documentation and code establish; do not invent shared rules.
